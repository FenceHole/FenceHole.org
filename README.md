# FenceHole.org — Hub + HQ

This repo is the **FenceHole Hub + HQ app** — the private team hub, client
portal, and AI agent operating system for Fence Hole LLC. It deploys to
**fencehole.org**.

The public-facing portfolio site (the one that lists Frances & Family, Cool
Cat Stuff, etc. for brands/sponsors) now lives in `portfolio-site/` and is
meant to be deployed separately to **fencehole.com**.

See `README-INSTALL.md` for setup steps (Supabase + OpenRouter).
